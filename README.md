---

## ✨ 它解决什么问题

竞赛型 PPT 不是把报告搬上幻灯片，而是一套有明确打分逻辑的传播设计：

- 评委只有几分钟 —— 需要**顶部章节导航 + 大标题即结论**
- 分析不能堆模型 —— 需要**模型页与结论强化页交替**
- 章节收尾要留钩子 —— 需要**深色蒙版单句总结页**
- 全场只能记一句话 —— 需要**20字以内核心观点贯穿**
- AI感会被扣分 —— 需要成体系的**去模板化约束规则**

本技能把以上全部经验固化为可执行指令，配合图像生成与PPT组装工具，从输入到成品一次跑通。

---

## 🔒 固定结构范式（所有输出强制执行）

| 范式 | 说明 |
|------|------|
| 🧭 顶部章节导航 | 占页面高7%，当前章节主强调色高亮，其余浅灰棕 |
| 💬 底部结论栏 | 占7%，每页一句话总结，**不重复标题**，说明数据意味着什么 |
| 🔁 模型↔结论交替 | 避免连续堆叠同类型页面 |
| 🌑 章节末总结页 | 复制上一页压暗至20%亮度 + 82%透明度深色蒙版 + ≤35字单句 |
| 🎯 核心观点贯穿 | ≤20字核心观点 + ≤20字核心问题，无关内容进备份页 |
| 🧩 方案分层亮相 | 解决方案先整体架构一页亮相，再逐模块拆解 |

## 🎨 四套预设竞赛色板

| 色板 | 主强调色 | 适用场景 |
|------|---------|---------|
| 🏜️ **沙漠戈壁风** | 沙金 `#C9962E` | 商科竞赛、管理咨询、文化传承、户外运动 |
| 🎓 **学术深蓝风** | 亮蓝 `#2E7DD7` | 学术论文、理工科案例、科技创新 |
| 🩺 **医学青绿风** | 海绿 `#2E8B57` | 医学案例、公共卫生、生命科学 |
| ⚖️ **经典酒红风** | 酒红 `#8B2635` | 法律案例、人文社科、公共政策 |

每套色板均含9个标准角色色值：深色主色 / 深色背景 / 主强调 / 次强调 / 警示 / 模块填充 / 正文背景 / 次要文字 / 安全色。完整定义见 [`skill/SKILL.md`](skill/SKILL.md) 步骤二。

## 五步工作流

```
输入解析 ──→ 色板锁定 ──→ 框架确认 ───→ 批量生图 ──→ 组装交付
(模式A/B)   (用户选定)   (逐页布局)   (每批5页并发)  (slidesCompose)
    │            │            │             │             │
 确认核心观点  锁定9色值+字体  用户确认框架   质量校验+重试   16:9 PPT成品
```

### 双输入模式

- **模式A · 逐页详细规范**：已有完整逐页规范 → 直接进入生图
- **模式B · 案例报告+核心观点**：只给报告文本 → 自动规划18–24页四章节结构（危机重识 → 失配定位 → 闭环重构 → 闸门落地，章节名可随主题替换，但"问题→诊断→方案→落地"逻辑不变）

## 🚀 使用方式

> 用「制作竞赛PPT」技能，根据这份案例报告帮我做一套XX大赛决赛答辩PPT。

复制 [`skill/SKILL.md`](skill/SKILL.md) 到你的技能目录即可。生图与组装步骤依赖平台能力（image generation / slides 工具），无对应工具时可将其作为纯设计规范文档使用。

## ⚠️ 数据与表达边界（内置硬约束）

- 公开数据必须标注来源与年份；MBA院校数 ≠ 招生人数
- 探索性问卷标注"探索性样本，不作全国外推"
- 不编造财务数据、用户评价、未授权Logo与人物照片
- 11万元级预算数字标注为"团队测算"
- 不使用"赋能/引领/打造生态"等空泛词而不说明具体动作

---

## 🙅 去AI感规则（精选）

- 连续两页不使用完全相同的卡片矩阵
- 不在每页放四个圆角矩形
- 不用随机渐变、霓虹线条、科技蓝光
- 不用复杂图标替代清晰文字；每页只有一个视觉中心
- 手写批注每页最多两处；正文不小于16pt
- 页面应像团队研究后的判断，而非咨询模板自动填充
